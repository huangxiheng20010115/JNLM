# AmpIFG-Net

**Amplitude-Assisted Unit-Complex Restoration for InSAR Phase Denoising**

This directory is the public release landing page for AmpIFG-Net, developed by Xiheng Huang and Jubo Zhu.

The reproducible implementation, trained-model provenance, evaluation configurations, and versioned evidence tables will be organized here. Dataset manifests and generation metadata will also be released, subject to the redistribution conditions of the source Sentinel-1 products. Raw or redistribution-restricted source SAR products will not be mirrored in this repository.

## Release status

The code and curated research artifacts are being prepared for a versioned public release. This landing page provides a stable repository location for the manuscript and will be updated as the release is finalized.
